First release of Buckshot Roulette for Nintendo Switch. It runs the game from your own Steam copy: no game files are included.

- Runs the whole game, locked at 30 fps, with LSFG frame generation for 60 frames on screen (needs your own Lossless.dll from Lossless Scaling).
- Minus menu: graphics (30 lock, 3D scale, sharpening, dynamic resolution, fps overlay, frame generation), per-bus volume, cheats.
- Right stick moves the cursor, ZR/ZL click, touch screen works too.
- Multiplayer is hidden (it needs Steam).

Install: unzip, run `build_pack.bat` (needs Python 3) to build the game pack from your Steam copy, copy the `switch` folder to your SD card, and start it from the homebrew menu in title mode (hold R while starting a game). See the README for details.

Known: the corridor into the club drops to about 17 fps for a few seconds at docked clocks; docked TV output is not tested much yet.
